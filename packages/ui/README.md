# BitL3 UI

Shared UI components for BitL3 applications.

Goals:

- Reuse consistent payment components across apps
- Keep accessibility standards centralized
- Support mobile-first layouts
- Avoid duplicated button, badge, card, and amount styles

Initial components:

- Button
- StatusBadge
- AmountDisplay
- Card
- QRBlock

This package starts as a lightweight source package and can later become a published internal package.
