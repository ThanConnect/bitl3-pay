# BitL3 Merchant Dashboard

The dashboard is the merchant-facing application for operating BitL3 payments.

Initial goals:

- View today's received amount
- View payment count and pending count
- Create payment request
- Review recent payments
- Manage API keys later
- Configure webhooks later
- Export reports later

Design direction:

- Mobile-first
- Simple language
- Large tap targets
- Accessible status labels
- Multi-language ready
