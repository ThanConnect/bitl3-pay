# BitL3 Payment Page

This app will provide the universal, mobile-first payment experience for BitL3 users.

Primary goals:

- Simple payment link UX
- QR-code-first payment flow
- Clear status labels
- Multi-language-ready copy
- Accessible layout
- Low-bandwidth friendly design

Initial pages:

- `/pay/:invoiceId` payment page
- `/receipt/:invoiceId` receipt page
- `/help` simple user help

Design principle:

The user should not need to understand Bitcoin, Lightning, payment hashes, or nodes to complete a payment.
