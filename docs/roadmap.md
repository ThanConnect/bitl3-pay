# BitL3 Pay Roadmap

## Phase 1: MVP

Goal: Build a practical Bitcoin Layer 3 payment API using Lightning.

Scope:
- Merchant API keys
- Invoice creation
- Payment status monitoring
- Ledger entries
- Webhook notifications
- Local development setup

## Phase 2: Dashboard and SDK

Scope:
- Merchant dashboard
- JavaScript SDK
- Payment reporting
- Webhook delivery logs

## Phase 3: Multi-asset payments

Scope:
- Taproot Assets research
- Stablecoin payment flow design
- Asset-aware invoice model

## Phase 4: Advanced Bitcoin-native contracts

Scope:
- RGB research
- Client-side validation model
- Asset marketplace prototype
